# Contributing

Thanks for looking. This repo is a reference setup from the [4-layer AI-first company series](https://github.com/bernardTavares), so the bar is "makes it clearer or more correct", not "adds features".

- **Questions or ideas:** open a thread in [Discussions](../../discussions).
- **Bugs or mistakes in the config:** open an issue with what you tried, the expected result and the actual result.
- **Pull requests:** keep them small and focused. Never include real tokens, chat IDs, hostnames or agent memory; use placeholders like the ones already in `config/openclaw.example.json`.
- **Security:** don't open a public issue; use GitHub's private vulnerability reporting on this repo.
